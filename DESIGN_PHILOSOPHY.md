# Marion Gospel Hall Hymn Book
## Design Philosophy

This project intentionally favors simplicity over features.

The goal is not to build the most powerful hymn application.

The goal is to create the closest digital equivalent to opening a printed hymnbook.

## Principles

1. The hymn is always the focus.
2. One tap should take the user to any hymn.
3. It should feel like opening a printed hymnbook, not operating a database.
4. Every control must earn its place.
5. Prefer removing UI over adding UI.
6. White space is a feature.
7. Use one consistent accent color throughout the app.
8. Features that require explanation should be reconsidered.
9. Design phone-first while remaining comfortable on tablets and in landscape orientation.
10. Font size should be adjusted with the built-in Aa control rather than whole-page zoom.
11. Consistency is more important than novelty.
12. Future additions should be measured by how little they distract from reading and singing the hymn.

## Guiding Question

When considering any change, ask:

> Does this make the app feel more like opening a printed hymnbook, or more like operating a database?

If the answer is the latter, the feature or design should be reconsidered.
